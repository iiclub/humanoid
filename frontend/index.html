Importing a .json by hand

One routine object, or { "dances": [ … ] } — the shape in config/dances.json. Arms are three motors each — shoulder_x, shoulder_y, elbow; wrists and grippers are never used by a dance and are dropped on import. Joints are travel percentages: shoulder_y 0 down / 65 straight out / 100 overhead · shoulder_x 0 at the side / 100 forward · elbow 0 straight / 100 folded · head_tilt 0 chin up / 50 level / 100 chin down. audio: { file, start, end } names the seconds it dances to; leave file out to use the built-in beat. A bare string in steps is a comment. Imported routines land on this page and in the mic's vocabulary at once.

Off by default. When on, the phone at /face listens for speech and answers through Ollama — tap the eyes to start it talking. When off, a tap only wakes the screen and goes fullscreen; the microphone stays closed. 🎤 Live dance takes the mic over either way and hands it back afterwards.

Wake sequence — head D4 + eyes, together

Walks the head servo on D4 from 0° to 70°, and as it passes the halfway point (35°) the eyes start opening — the two overlap, which is what makes it read as waking up rather than two separate movements. The lids are given exactly the time the head has left, so both arrive together however long you set it to. Runs on the server, so closing this tab will not abandon it half way. Torso lift on the right-hand NodeMCU.

Torso up lifts while you hold it — and lowers on its own the moment you let go. Torso down is the plain manual version: it lowers while held and stops on release. There are no limit switches, so every run is capped at 4 s: hold past that and the motor parks itself until you ask for something else. The firmware enforces the same cap independently, and stops too if commands go quiet — a closed tab or dead WiFi cannot leave it running. E-STOP blocks it entirely.

How a NodeMCU joins the network
  1. Power it up. With no stored WiFi it starts an access point (e.g. HUMANOID-RIGHT, password 12345678).
  2. Join that AP from your phone/laptop, open http://192.168.4.1.
  3. Pick your WiFi, type the password, and enter this laptop's IP (shown top-left) and port.
  4. It reboots, joins your WiFi and POSTs its IP to /api/register; it then appears below.
  5. If the WiFi disappears for more than ~15 s it drops back into access-point mode by itself.
