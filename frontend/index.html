Wake sequence — head D6 + eyes, together

Walks the head servo on D6 from 0° to 70°, and as it passes the halfway point (35°) the eyes start opening — the two overlap, which is what makes it read as waking up rather than two separate movements. The lids are given exactly the time the head has left, so both arrive together however long you set it to. Runs on the server, so closing this tab will not abandon it half way. How a NodeMCU joins the network
  1. Power it up. With no stored WiFi it starts an access point (e.g. HUMANOID-RIGHT, password 12345678).
  2. Join that AP from your phone/laptop, open http://192.168.4.1.
  3. Pick your WiFi, type the password, and enter this laptop's IP (shown top-left) and port.
  4. It reboots, joins your WiFi and POSTs its IP to /api/register; it then appears below.
  5. If the WiFi disappears for more than ~15 s it drops back into access-point mode by itself.

initial is the home angle (0 or 180) — travel always starts there and runs to the opposite end. dir flips a mirrored servo. trim corrects horn-spline offset. Changes save to config/setup.json immediately.
